## 1. Цель и задание

Цель работы: изучить порядок анализа учебной корпоративной сети, определить расположение контроллера домена и проверить возможность получения сведений о доменном пользователе в лабораторном сценарии Ampire.

Согласно методическим указаниям, исходная сеть имеет адрес **195.239.174.0/24**. Необходимо обнаружить контроллер домена, а затем найти флаг в одном из полей пользователя **Flag**. Узел **195.239.174.12** исключен из атакуемых адресов.

Работа проводилась в учебном окружении Kali Linux с применением Nmap, Metasploit Framework, ProxyChains и средств анализа служб Windows и Active Directory.

## 2. Ход выполнения работы

### 2.1. Разведка сети и выбор начальной точки доступа

На первом этапе была выполнена разведка доступных сетевых узлов и проверены опубликованные сервисы. В качестве возможных точек входа рассматривались почтовый сервер Microsoft Exchange и корпоративный веб-сайт. На снимках экрана зафиксированы результаты сетевого анализа и обращения к сервисам.

Почтовый сервер был доступен через веб-интерфейс Outlook. Для него проводился поиск подходящих модулей Metasploit. Параллельно исследовался корпоративный сайт на WordPress.

Далее приводятся основные подтверждающие изображения из предоставленного архива. Некоторые промежуточные или повторные попытки опущены, чтобы не перегружать отчет.

На данном этапе применялись процедуры инвентаризации хостов и сопоставления найденных служб с возможными направлениями дальнейшего исследования.

После перехода к внутренней сети был изучен адресный диапазон **10.10.10.0/24**. Сессионная маршрутизация и SOCKS-прокси использовались для работы с узлами, которые не были доступны непосредственно с внешней машины.

### 2.4. Проверка состояния безопасности контроллера домена

При анализе контроллера домена проверялось наличие известной уязвимости **Zerologon (CVE-2020-1472)**. На одном из снимков средство проверки вывело результат **VULNERABLE** для узла 10.10.10.20.

В учебном сценарии затем была зафиксирована успешная работа соответствующего модуля Metasploit. По результатам дальнейшего исследования были получены сведения об учетных записях домена. Скриншоты показывают также отдельные неудачные попытки установления сессии перед успешным подключением.

## 3. Полученные результаты

В ходе лабораторной работы исследована учебная сеть Ampire, рассмотрены внешние точки входа, определен внутренний диапазон адресов и найден контроллер домена по адресу **10.10.10.20**. Подтверждено наличие уязвимости Zerologon, показана активная Meterpreter-сессия с контроллером и получен список доменных учетных записей. Искомая учетная запись **Flag** присутствует в полученном списке. При этом вывод свойства пользователя с самим значением флага на предоставленных скриншотах подтвержден.

## 4. Вывод

В результате выполнения работы были отработаны основные этапы анализа учебной корпоративной инфраструктуры: разведка узлов, анализ доступных сервисов, поиск внутренней сети, определение контроллера домена и проверка выявленной уязвимости. Практическая часть показала, что уязвимость критичного доменного сервиса может привести к компрометации учетных записей и получению доступа к инфраструктуре Active Directory.
